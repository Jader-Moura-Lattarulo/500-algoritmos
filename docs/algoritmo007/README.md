# Algoritmo 007 — Fazer uma prova

## Descrição

Este algoritmo representa o processo de realização de uma prova,
considerando a existência de questões em branco e o tempo disponível
para sua resolução.

Durante a prova, o aluno verifica cada questão e decide se irá
resolvê-la ou passar para outra questão.

## Objetivo

Representar uma estrutura de repetição que depende de duas condições:
a existência de questões em branco e a disponibilidade de tempo.

## Passos

1. Ler a prova.
2. Pegar a caneta.
3. Enquanto houver questão em branco e o tempo não tiver terminado:
   - Se souber a questão, resolvê-la.
   - Senão, pular para outra.
4. Entregar a prova.
