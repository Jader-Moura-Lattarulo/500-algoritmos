# Algoritmo 005 — Fazer um bolo simples

## Descrição

Este algoritmo representa as etapas necessárias para fazer um bolo
simples, utilizando condições para determinar algumas ações durante
o preparo.

## Objetivo

Descrever o processo de preparação de um bolo considerando se a roupa
é branca e se há uma batedeira disponível.

## Passos

1. Pegar os ingredientes.
2. Se estiver usando roupa branca, colocar avental.
3. Se tiver batedeira, bater os ingredientes na batedeira.
4. Senão, bater os ingredientes à mão.
5. Colocar a massa na forma.
6. Colocar a forma no forno.
7. Aguardar o tempo necessário.
8. Retirar o bolo.

## Conceitos

- Algoritmo
- Sequência de instruções
- Condições
- Estrutura de decisão
- `se`
- `senão`
