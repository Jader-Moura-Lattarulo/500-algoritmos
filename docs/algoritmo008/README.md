# Algoritmo 008 — Jogo da forca

## Descrição

Este algoritmo representa o funcionamento básico do jogo da forca,
no qual o jogador tenta descobrir uma palavra informando letras.

A cada tentativa, o algoritmo verifica se a letra pertence à palavra.
Quando a letra é acertada, ela é preenchida na lacuna correspondente.
Quando é errada, uma parte do corpo é desenhada na forca.

## Objetivo

Representar uma estrutura de repetição que continua enquanto existirem
lacunas vazias e o corpo do personagem ainda estiver incompleto.

## Passos

1. Escolher a palavra.
2. Montar o diagrama do jogo.
3. Enquanto houver lacunas vazias e o corpo estiver incompleto:
   - Se acertar uma letra, escrever na lacuna correspondente.
   - Senão, desenhar uma parte do corpo na forca.
