# Algoritmo 004 — Fim de semana

## Descrição

Este algoritmo representa uma rotina simples para um fim de semana,
utilizando uma condição para decidir o que fazer de acordo com a
previsão do tempo.

## Objetivo

Definir as atividades do fim de semana considerando se fará sol ou não.

## Passos

1. Ver a previsão do tempo.
2. Se fizer sol, ir à praia.
3. Senão, estudar.
4. Almoçar.
5. Ver televisão.
6. Dormir.

## Conceitos

- Algoritmo
- Sequência de instruções
- Condições
- Estrutura de decisão
- `se`
- `senão`
