# Algoritmo 006 — Descascar batatas

## Descrição

Este algoritmo representa o processo de descascar batatas, utilizando
uma estrutura de repetição para executar a mesma ação enquanto ainda
houver batatas para descascar.

A quantidade de batatas é informada pelo usuário e, a cada repetição,
uma batata é descascada até que não restem mais batatas.

## Objetivo

Praticar uma estrutura de repetição que permite executar uma instrução
diversas vezes enquanto uma determinada condição for verdadeira.

## Passos

1. Pegar faca, bacia e batatas.
2. Colocar água na bacia.
3. Informar a quantidade de batatas.
4. Enquanto houver batatas:
   - Descascar uma batata.
   - Diminuir a quantidade de batatas restantes.
5. Informar que todas as batatas foram descascadas.
