# Algoritmo 003 — Trocar uma lâmpada

## Descrição

Este algoritmo apresenta uma sequência de instruções para trocar uma
lâmpada queimada.

Diferentemente dos algoritmos anteriores, este exemplo introduz uma
estrutura de decisão, utilizando condições para determinar se algumas
ações são necessárias.

## Objetivo

Representar as etapas necessárias para trocar uma lâmpada, considerando
diferentes situações que podem ocorrer durante o processo.

## Passos

1. Verificar se a lâmpada está fora de alcance.
2. Se estiver fora de alcance, pegar uma escada.
3. Pegar a lâmpada.
4. Verificar se a lâmpada está quente.
5. Se estiver quente, pegar um pano.
6. Retirar a lâmpada queimada.
7. Colocar uma lâmpada boa.

## Conceitos

- Algoritmo
- Sequência de instruções
- Condições
- Estrutura de decisão
- `se`
