# Algoritmo 002 — Mascar um chiclete

## Descrição

Este algoritmo demonstra que até uma atividade cotidiana simples pode
ser descrita como uma sequência de instruções.

## Objetivo

Representar, de forma ordenada, as etapas necessárias para mascar um
chiclete.

## Passos

1. Pegar o chiclete.
2. Retirar o papel.
3. Mastigar.
4. Jogar o papel no lixo.

## Conceitos

- Algoritmo
- Instruções
- Sequência de execução
- Ordenação de passos
