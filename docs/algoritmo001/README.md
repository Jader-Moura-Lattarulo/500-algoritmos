# Algoritmo 001 — Fritar um ovo

## Conceito

Este algoritmo apresenta o conceito de algoritmo como uma sequência
ordenada de instruções necessárias para realizar uma tarefa.

## Objetivo

Representar, de forma estruturada, as etapas necessárias para fritar
um ovo.

## Conceitos praticados

- Algoritmo
- Instruções
- Sequência
- Ordem de execução

## Fluxo

1. Separar os ingredientes e utensílios.
2. Preparar a frigideira.
3. Aquecer o óleo.
4. Adicionar o ovo.
5. Finalizar o preparo.
