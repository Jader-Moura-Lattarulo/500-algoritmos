# 500 Algoritmos

Projeto de estudo baseado no livro **Introdução à Programação — 500 Algoritmos Resolvidos**, de **Anita Lopes e Guto Garcia**.

O objetivo é resolver os algoritmos propostos no livro utilizando diferentes linguagens de programação, praticando **raciocínio lógico, fundamentos de programação e as particularidades de cada linguagem**.

## 🎯 Objetivos

* Desenvolver e fortalecer o raciocínio lógico.
* Praticar resolução de problemas através de algoritmos.
* Implementar os mesmos problemas em diferentes linguagens.
* Comparar diferentes formas de resolver um mesmo problema.
* Praticar boas práticas de organização e documentação de código.
* Evoluir progressivamente para testes automatizados.
* Disponibilizar uma interface web para executar os algoritmos de forma interativa, sem necessidade de utilizar o terminal.

## 🧑‍💻 Linguagens

As implementações serão desenvolvidas nas seguintes linguagens:

* **Python**
* **PHP**
* **Java**
* **C#**

A ideia é que cada algoritmo seja implementado nas quatro linguagens, permitindo comparar suas sintaxes, recursos e diferentes formas de estruturar a mesma solução.

## 🧠 Como os algoritmos serão organizados

Cada algoritmo poderá possuir sua própria documentação e implementação.

Exemplo:

```text
Python/
└── algoritmo028/
    ├── README.md
    └── main.py
```

O `README.md` de cada algoritmo poderá apresentar:

* Descrição resumida do problema.
* Conceitos praticados.
* Exemplos de entrada e saída.
* Observações sobre a solução.

## 🔄 Comparação entre linguagens

Um dos principais objetivos do projeto é resolver o **mesmo problema em diferentes linguagens**.

Por exemplo:

```text
Algoritmo 028

Python  ✓
PHP     ✓
Java    ✓
C#      ✓
```

Dessa forma, além de praticar lógica de programação, será possível observar como conceitos semelhantes são implementados em diferentes ecossistemas.

## 🧪 Testes

Conforme o projeto evoluir, os algoritmos também poderão receber testes automatizados.

A intenção é testar diferentes cenários de entrada e verificar se os resultados produzidos correspondem aos resultados esperados.

## 🌐 Interface Web

Além das implementações no GitHub, este projeto pretende possuir uma interface web para permitir que os algoritmos sejam experimentados de maneira visual e interativa.

A ideia é possibilitar que o usuário:

1. Escolha um algoritmo.
2. Informe os valores necessários.
3. Execute a solução.
4. Visualize o resultado.
5. Consulte a implementação utilizada.
6. Compare as implementações entre as linguagens.

A aplicação web será desenvolvida e evoluída separadamente conforme o projeto avançar.

## 📌 Sobre o projeto

Este projeto não tem como objetivo apenas completar uma lista de exercícios.

A proposta é utilizar os **500 algoritmos como uma jornada de aprendizado**, começando pelos fundamentos de lógica de programação e evoluindo gradualmente para conceitos mais complexos de desenvolvimento de software.

Cada algoritmo representa uma oportunidade de praticar, comparar abordagens e entender melhor as ferramentas utilizadas no desenvolvimento de software.
